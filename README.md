# branching-lab.-
## Project Description
This project demonstrates basic Git workflows.  
It helps beginners understand branching, committing, and collaboration.
1.	Create and switch between branches in a Git repository
2.	Make isolated changes on a feature branch
3.	Push a branch to a remote GitHub repository
4.	Open a Pull Request (PR) from a feature branch
5.	Review, comment on, and merge a Pull Request
6.	Resolve a simple merge conflict
